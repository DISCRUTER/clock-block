# clock-block
A helper extension to permit distraction for a certain period of time.

## File Structure
```
clock-block/

  content_script/
    inspector.js

  icons/
    clock-block-32.png
    clock-block-light-32.png
    clock-block-48.png

  popup/
    index.html
    styles.css
    script.js

  manifest.json
```

## Application Features
- Block websites and allow access only for a certain period of time.
- Custom redirect to a site of your choice for breaking curfew.
